qplay media components

The exact runtime archive, file SHA256 values and source references are recorded
in upstream-lock.json. The pinned mpv, FFmpeg, ffprobe and yt-dlp executables
and native player assets are included in qplay's installer and portable
archive. No upstream installer is run. Updates require an intentional lock change.

Qt 6.12.0
  qplay distributes Qt Core, GUI, QML and Quick libraries and their required
  plugins from the pinned Qt 6.12.0 Windows SDK. Qt is available under LGPL-3.0
  or GPL-3.0; Qt-LGPL-3.0.txt accompanies this notice and qplay's LICENSE
  contains GPL-3.0. The DLLs and plugins remain separately replaceable.
  Source: https://download.qt.io/official_releases/qt/6.12/6.12.0/single/
  Module and third-party license details:
  https://doc.qt.io/qt-6/licenses-used-in-qt.html

Microsoft Visual C++ Runtime
  Unmodified x64 Microsoft.VC143.CRT DLLs from the native compiler's matching
  Visual Studio VC/Redist distribution accompany qplay.exe for offline playback.
  build-manifest.json records the toolset, redistributable cohort, installer hash
  and each bundled DLL hash. The Redistributable license is MSVC-Runtime.rtf.
  Microsoft permits redistribution of these VC/Redist files under its terms:
  https://learn.microsoft.com/visualstudio/releases/2022/redistribution
  The Windows 10/11 Universal C Runtime remains an operating system component.

mpv
  Source: https://github.com/mpv-player/mpv/tree/b2c255c13e8e37952dbac6c34da56a690560378b
  The public qbutt 1.3.0 runtime supplies this build with its frozen MSYS2
  CLANG64 dependency closure. qplay retains these exact runtime binaries.
  Copyright and GPL/LGPL texts accompany this notice.
  qplay embeds libmpv in its Rust/CXX-Qt process. The original mpv executable is
  also bundled for callers that discover it through --runtime-info-json.
  The source archive pinned below preserves the custom build recipe, exact source
  inputs, original MSYS2 PKGBUILDs and patches, package BUILDINFO/PKGINFO, source
  archives, VCS trees and Cargo dependencies for the linked runtime and static
  libraries. Its manifests bind those inputs to the bundled binary closure.
  upstream-lock.json pins that complete source archive by URL, size and SHA256.
  BUILDING.txt in the archive describes the recorded toolchain and rebuild steps.
  libplacebo by Niklas Haas and contributors is under LGPL version 2.1 or later;
  its pinned license is libplacebo-LGPL-2.1.txt.

FFmpeg and ffprobe
  GPL version 3 or later, shared MSYS2 CLANG64 FFmpeg 9.0.2-6 build.
  The original package BUILDINFO, PKGBUILD, patches and exact source archive are
  retained in the media-sources ZIP, together with its linked dependencies.
  Original package license texts accompany the DLLs under engine/licenses/msys2.
  FFmpeg and ffprobe are placed beside their DLL closure at engine/. The absolute
  tool paths returned by qplay work without changing a caller's working directory
  or PATH. The original upstream archive inventory remains pinned in the lock;
  the final installed locations are recorded in build-manifest.json.

yt-dlp
  Source: https://github.com/yt-dlp/yt-dlp/tree/2026.08.19
  The Windows executable combines yt-dlp and dependencies under GPL version 3+.
  Upstream Unlicense, GPL version 3 and third-party notices accompany this notice.
  The pinned source archive retains exact yt-dlp, CPython, PyInstaller, frozen Python
  package, curl native dependency and EJS source inputs and controlling recipes.
  Its manifest describes the verified binary/source bindings and their scope.

HTTPS trust store
  certifi 2026.7.22 supplies the pinned Mozilla CA collection under MPL-2.0.
  Source archive URL, SHA256 and PEM member are recorded under tlsTrustStore
  in upstream-lock.json; the release build-manifest.json records the PEM hash.
  The exact source archive is also retained in the pinned source archive
  under yt-dlp/source-export/sdists. certifi-MPL-2.0.txt retains its full license.
  mpv verifies HTTPS certificates and host names using this collection together
  with native Windows trust. Certificate verification remains enabled.

Player interface and shaders
  The native interface uses Tabler Icons outline v3.49.0 under the MIT license.
  Exact SVG provenance and the license are in assets/icons/UPSTREAM.txt and
  assets/icons/LICENSE in the qplay source distribution.
  Anime4K and FSR shaders retain their individual license headers in shaders/.

qplay adaptations and corresponding sources
  https://github.com/qbutt-org/qplay maintains the native player, profile,
  changed manager/bootstrap sources, Cargo locks, package recipes and notices.
  The manager binary's SHA256 and first qplay revision are pinned separately
  from the original qbutt profile snapshot in upstream-lock.json.
  The public qbutt snapshot and original profile provenance are recorded under
  importedFrom and importedProfileHashes in upstream-lock.json. Original imported
  hashes record that baseline; build-manifest.json binds each qplay package to
  its actual modified files. Private repository history is not distributed.
  qplay supplies asynchronous read-only GPU selection and stores generated runtime
  data only in its own data directory. No global mpv profile, registry environment
  variables or machine-local shader benchmark profile are installed.

  The unchanged engine's complete corresponding sources and rebuild inputs are:
  https://github.com/qbutt-org/qplay/releases/download/v1.0.0-sources/qplay-1.0.0-runtime-sources.zip
  Size: 1432941010 bytes
  SHA256: ed37bcf1f833e392ab5c71132e79de7efb27164c1611e0134ed0c6ce08718a4a
  Its BUILDING.txt and manifests describe exact revisions, dependency closure,
  binary/source mappings and the build commands. The qplay source distribution
  supplements that immutable archive with all changed qplay code and recipes.

Frame generation
  Manager and bootstrap sources, Cargo locks, build recipes and generated notices
  are maintained under profile/tools in the qplay source distribution.
  The compiled Rust notices and pinned standard-library notice accompany the
  executables under engine/profile/tools/bin. Runtime-specific notices are copied
  by the manager from profile/tools/framegen-manager/notices.
  The modified Intel VSOV plugin has complete source/build instructions and
  modification provenance under profile/tools/framegen-vsov.
  The Intel RIFE graph has provenance under profile/framegen/models/openvino.
  Additional runtime downloads are individually pinned in the manager catalog.
